# 超星课程任务助手 · Edge 扩展 0.5.9

本机 Manifest V3 扩展，使用 WXT、React 和 TypeScript。固定浅色界面，主导航为「待办 / 当前页 / 设置」。打开题目只检测标题、题数和可用操作；识别、参考、填写、保存和提交由用户分别启动。

本版自动学习始终在前台运行。标签页或窗口焦点变化时扩展会重新激活当前任务页；暂停、停止或遇到平台拦截后会释放前台控制。视频、音频、文档、图片和章节题共用同一控制器。升级见 [0.5.9 升级说明](docs/upgrade-0.5.9.md)，可重复的本地检查见 [验收说明](docs/acceptance.md)。

本项目是独立的第三方浏览器扩展，与超星 / 学习通无隶属关系。使用前请阅读 [隐私说明](PRIVACY.md)、[安全报告说明](SECURITY.md) 和 [许可证](LICENSE)。

## 安装与升级

1. 解压 `chaoxing-task-assistant-0.5.9-edge.zip` 到固定目录，或使用 `dist/edge-unpacked`。
2. 打开 `edge://extensions`，开启开发人员模式，加载包含 `manifest.json` 的目录。
3. 已安装旧版时，替换原目录中的文件，在扩展页点击「重新加载」，再刷新学习通页面。保留扩展安装身份，以保留本机配置和历史。
4. 在设置中配置自己的 OpenAI 兼容模型服务和 API Key。安装包没有预置密钥。最低 Chromium 内核版本为 116。

保留 schema 2。模型设置、课程、普通作业、通知记录和执行历史保存在本机扩展存储中；浏览器重启后，执行队列和学习队列均暂停，由用户核对后继续。

## 跟随页面

- 学习通首页展示待办，按「作业 / 任务点」分类。
- 课程目录或作业列表展示当前课程的待办。
- 具体题目页展示当前页工作台。
- 已提交、已过期和只读预览可以识别、生成参考、核对及导出，独立于待办和批量队列。

默认跟随浏览器页面。主动查看总览、详情、队列或设置后保持当前位置；点击「返回当前页」恢复跟随。

## 当前页操作

1. 点击「识别文字」，读取完整题目，运行所选 OCR / 视觉策略并复核文字。
2. 点击「生成参考答案」，仅生成候选，不填写页面。参考模式也会为已有答案的题目重新求解。
3. 点击「填写答案」，重新核验页面和已有答案，填写后回读。默认保留已有答案并补空，可选择覆盖重做。
4. 选择「保存草稿」或「提交」。草稿保存必须核验服务器答案；证据不足显示保存待确认。提交要求完整、无检查项且回读一致；结果不明先核验，不重复提交。

「一键处理」保留「一键完成并提交 / 一键完成并保存草稿」。普通作业可以批选执行；草稿模式允许填写文字可靠但模型不确定的候选，识别失败及不支持题目跳过并列出待检查题号。只读页面不能填写、保存或提交，后台也限制这些操作。

支持文字单选、多选、判断、多空填空，以及题干和选项中的文字、数学公式图片。按页面提供的选项键写入原生输入框及 UEditor。图表、照片、媒体、简答及附件等无法完整转录的内容进入人工检查。

「查看题目与答案」打开独立详情页，每页 20 题，支持题号跳转、需检查及与参考不同筛选。返回入口始终可见，并保留分页和滚动位置。每题可重新识别、重新作答或人工确认；这些操作不会直接填写或提交。

「我的答案」「模型参考」「平台公布答案」分开展示。与模型参考不同只表示待核对；平台明确公布的答案才用作标准答案依据。

## TXT 导出

默认导出题型、题干和选项，可加入本人答案、参考答案和解析，并注明来源。使用 UTF-8 BOM 和 Windows 换行；公式保留文本或 LaTeX，未确认内容明确标注。导出只使用已有识别结果，不隐式读取页面或调用模型。尚未识别时先点击识别文字。

## 列表刷新与自动学习

登录后更新一次，浏览器运行期间每 30 分钟更新课程汇总和所有在读课程的普通作业列表；执行、学习或手动处理期间暂停自动刷新。默认排除结束及退课课程。

自动刷新仅读取课程列表、必要导航外壳、普通作业列表及分页，不读取章节目录、章节卡片、视频或题目，不调用模型。界面切换使用缓存。全局「刷新进度和作业」和单课程「刷新作业列表」分别显示更新时间。列表读取失败保留旧信息，不显示成没有作业。扩展主动的列表、章节卡片读取及导航共用最小 1 秒访问间隔，只补足距上次实际派发不足的时间；只读缓存为 5 分钟，缓存命中及已加载页面不占用间隔。

任务点 `1/65` 表示已完成 1 个、总共 65 个，剩余 64 个任务点，不推断章节数或视频数。

「任务点 → 开始前台学习」选择课程及视频、音频、文档/PPT、图片阅读、章节题，可分别勾选且默认全选。旧队列保留原处理范围。选择章节题时同时指定提交 / 草稿目标。启动后才读取目录，按「当前卡片读取 → 执行 → 下一卡片 → 下一章节」推进；普通资源不计任务点，讨论、签到、直播和未知类型保留「打开检查」入口。

自动学习始终在前台标签页执行。学习期间切换标签页或窗口时，扩展会自动激活当前任务页并聚焦窗口；窗口最小化时先恢复窗口。控制器核验真实激活状态，连续三次失败会暂停并记录 `foreground-unavailable`。暂停、停止、队列结束、账号变化及验证码／限流会释放前台控制。聚焦只切换焦点，不刷新页面或重建播放器。

音视频静音播放，优先使用平台原生支持的 2 倍速，不支持时正常播放。设置可改为正常速度，当前任务使用启动时的设置；界面显示实际速率，不强制覆盖平台限制。原生播放器按实际 iframe 的任务标识定位，支持嵌套及多个播放器。启动最多等待 30 秒，连续 60 秒无进展进入恢复；普通故障最多恢复 2 次，仍失败记录问题并继续。每次恢复前重新激活并核验学习页。切换标签页或窗口时会自动返回学习页。

文档/PPT和图片使用绑定到对应任务的原生阅读器，从第一页顺序阅读，或按一个可视区域逐屏滚动。每次核对内容加载、页码或真实位移；滚动到末尾后等待底部稳定至少 1 秒。阅读节奏默认 250 毫秒，可设 250–5000 毫秒，从动作实际发出时计时，不叠加确认耗时。当前资源保留启动时的设置，局部检查和 5 秒心跳独立运行。未知页数显示实际滚动位置；浏览器内置或无法访问的阅读器提供人工入口。初始化、翻页或内容加载超过 30 秒会报告结构化错误，并进入有限恢复。监听所属任务的完成标记后读取最新服务器；明确时长要求仍需满足。完成核验每轮最多三次，无额外固定等待。

章节题及可识别的标准答题 iframe 弹题复用现有作答、填写、回读和提交核验。草稿不计完成；播放器自定义弹题或无法可靠控制的阅读器进入检查，不推断成功。保存 / 提交不确定时保留核验保护，不重复提交。

学习期间保持当前任务页前台。需要处理另一页的填写、保存或提交时，先暂停学习，再使用当前页工作台；共享识别额度及串行答题通道仍有效。标签页或账号绑定失效后停止播放；浏览器重启后队列暂停，由用户继续。

## 识别及模型设置

默认答题服务为 `https://api.xiaomimimo.com/v1`，模型 `mimo-v2.6-pro`，通过 Chat Completions 请求。可配置任意兼容服务，支持 Bearer / api-key 认证、独立视觉服务和受限高级 JSON 参数。切换域名时申请对应访问权限。

文字策略可选仅 OCR、仅多模态、OCR → 多模态、多模态 → OCR，默认 OCR → 多模态。OCR 校验默认开启，检查两次识别、一致性、置信度及填空位置；关闭只放宽 OCR 文字校验，不关闭页面绑定、答案校验、回读和提交核验。

题目图片有独立策略，默认多模态 → OCR。公式转录保留上下标、分式、极限条件和分段函数；无法可靠确认二维结构时进入复核。视觉阶段忠实转录，不解题。人工确认只解除文字问题，不解除题型、答案键或其他结构问题。

OCR 复用最多两个工作器，低资源或初始化失败时降为一个。片段 OCR 失败后立即视觉兜底，与其他片段 OCR 重叠。视觉全扩展共享并发默认 5，可设 1–128，完成一个立即补位，获得名额后才生成图片。答题仍串行，每批最多 5 题，批次返回即可显示候选。

默认单请求超时 180 秒，临时故障最多重试两次；服务级失败停止后续派发。无效答题 JSON 仅修复一次。已确认文字、证据和候选分开缓存，总会话预算 6 MiB；模型变更不会清除可靠 OCR 或人工确认文字。实际视觉服务变化会使相关结果失效。

密钥仅存于可信扩展上下文，内容脚本无法读取；密钥输入为空保留旧值，可单独清除。日志及导出不含密钥、Cookie、签名、完整响应、字体或图片。OCR 代码、WASM、语言资源随扩展打包，不从 CDN 加载。

## 进度与开发者模式

顶部统一显示当前阶段、实际片段数量、耗时及暂停 / 取消 / 详情入口。模型等待显示实际请求耗时、超时限制和请求次数，不虚构预计完成时间。5 秒心跳与实际进展分别记录；30 秒连接异常提示，60 秒失联中止。关闭、重新打开侧栏可重新同步。

平台访问仅在确有剩余间隔时显示「等待访问间隔」和剩余时间，放行立即显示「正在读取」；缓存命中显示「使用缓存」。详情和开发者日志区分页面、缓存、网络、共享请求，并记录实际等待时长及扩展主动派发次数。该次数不包含浏览器加载整页所产生的所有子资源请求。

设置中的开发者模式默认关闭。开启后查看运行卡片、阶段时间线及可展开请求记录，支持运行、任务、阶段、级别筛选和 JSON / 文本导出。日志保留 7 天、最多 100 次已结束运行，活动运行保留；心跳不逐条写入日志。

## 验证码和限流

验证码、9010、平台限流、换号或登录失效立即暂停，不自动重试。手动完成验证后点击恢复，执行和学习队列仍需用户继续。访问间隔不能保证平台始终不要求验证，不提供验证码自动识别或绕过流程。

## 权限、数据流与使用边界

扩展请求 `storage`、`alarms`、`notifications`、`sidePanel`、`offscreen`、`scripting`、`tabs` 和 `webNavigation` 权限；默认站点访问范围是 `*.chaoxing.com` 与 `api.xiaomimimo.com`。选择其他模型服务时，浏览器会按需请求对应站点权限。`https://*`、本机 HTTP 服务和回环地址仅作为可选访问权限，不会在安装时自动授予。

登录后及之后每 30 分钟，扩展读取课程汇总和普通作业列表；此流程不读取题目、章节卡片、视频内容或调用模型。只有用户打开任务并启动识别、参考或学习操作后，扩展才读取对应页面内容。验证码、平台限流、登录失效或账号变化会暂停访问，不自动重试或绕过验证。

题目识别、模型测试或生成参考时，请求会把对应题目文字、选项以及所选视觉流程需要的图片发送到设置中指定的模型服务。服务地址、模型和 API Key 由用户配置；请求不携带浏览器 Cookie。模型服务方的数据保留和处理方式由其自己的隐私政策决定。扩展不会因为打开题目页而自动发起模型请求。

课程、任务、队列和历史存于浏览器扩展的本机存储；临时工作区和准备结果使用会话存储，开发者日志使用本机 IndexedDB，并按 7 天 / 100 次已结束运行的规则清理。密钥只在可信扩展上下文中使用，不写入日志或导出。扩展内置 OCR 代码与语言资源，不从 CDN 加载。更多细节见 [隐私说明](PRIVACY.md)。

生成参考只产生候选，不会填写答案。填写、保存草稿和提交是单独步骤；用户应先核对题目、答案和课程规则，并仅对有权访问的内容使用本扩展。扩展不会自动识别或绕过验证码，也不保证平台会接受自动化操作。

## 源码与验证

开发调试说明见 [自动调试说明](docs/debugging.md)。调试配置和运行记录只应保留在本机，不要提交账号、课程、题目、页面截图或凭据。

```powershell
npm.cmd ci
npm.cmd run typecheck
npm.cmd run test
npm.cmd run preview
npm.cmd run release
```

预览和测试仅使用合成数据，不操作真实平台。性能模拟运行 `npm.cmd run benchmark`；脚本使用合成页面和受控延迟，不访问旧 Git 历史、真实 OCR 引擎或模型服务。

交付目录含可加载扩展、扩展 ZIP、源码 ZIP、说明和 SHA256 校验和。源码 ZIP 包含源代码、测试和开源政策文件，不包含本机调试配置、运行日志、平台截图或验收材料。CI 与本地发布命令会分别检查类型、测试、打包和运行依赖。
