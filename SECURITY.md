# Security policy

## Reporting a vulnerability

Please do not post credentials, private course data, exploit details, or an unpatched vulnerability in a public issue. Once GitHub private vulnerability reporting is available for the repository, use **Report a vulnerability** to send a private report. If that option is unavailable, contact the maintainers through the contact method listed on the repository page and include only the information needed to reproduce the issue safely.

Include the affected version, browser and operating system, impact, reproduction steps, and a proposed mitigation if known. Redact account identifiers, cookies, signed URLs, question content, and API keys from logs and screenshots.

## Supported versions

Security fixes target the latest published release. Older versions may no longer receive updates.
