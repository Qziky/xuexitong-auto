# 答题请求设置

「设置 → 答题请求」将两个参数分开保存：

| 参数         | 默认 | 范围 | 含义                     |
| ------------ | ---- | ---- | ------------------------ |
| 同时请求数   | 3    | 1–50 | 同时发送几个答题模型请求 |
| 每个请求题数 | 5    | 1–50 | 每个请求最多带几道题     |

保存后从下一次生成参考生效，卡片显示已保存值，生成进度显示本次采用的并发和批量。旧配置自动补上默认值，不会把原有识图并发当成答题并发。

例如有 25 道待答题，设置同时请求数 5、每批 5 题，会发送最多 5 个并行请求；同时请求数设为 50 也只需要这 5 个请求。每批题数设为 50 时，25 题则放在一个请求中。

先从默认值开始，根据模型服务的并发额度调整。遇到模型限流时降低同时请求数，输出不完整时降低每个请求题数。图片转录仍使用「文字识别」中的独立并发设置。

生成参考仍是单独的用户操作，不会自动填写、保存或提交。并行返回的候选按题目 ID 归位；取消会停止尚未发送和正在等待的同组请求，批次失败时停止后续批次。已完成候选保留供核对，后续页面填写沿用原有顺序。
