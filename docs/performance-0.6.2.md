# 0.6.2 缓存验证记录

本版修复缓存有效性判断，未开展新的速度基准测试，不声称提升真实平台识别速度。

本地类型检查及 76 个测试文件中的 719 项测试通过。新增回归覆盖失败图片与空候选的重试、设置变化后的失败题目排除，以及原图到期、容量淘汰、清除、归属变化和取消操作。缓存检查只读取本机材料，最多并发检查四道题，不自动请求平台或模型服务。

已确认文字可以继续复用；仍引用原图的题目必须通过本机材料可用性检查。原图已完整转为文字或公式的题目不再依赖图片缓存。实际安装的 Edge 扩展与真实课程侧栏尚未完成本版验收。

已有合成识别基准的运行方法和范围见 [0.6.0 性能记录](performance-0.6.0.md)。该基准不能代替本版的原图生命周期或真实课程验收。
