# 0.6.3 图片地址与许可验证记录

本版修复旧题目图片地址使用 HTTP 时被过滤的问题。仅将精确匹配的 `p.ananas.chaoxing.com` 和 `p.cldisk.com` 公共图片 CDN 地址规范为 HTTPS。课程页面、其他 HTTP 来源、含凭据的地址和非默认端口仍不作为题目图片来源。

本地类型检查、76 个测试文件中的 732 项测试、MV3 扩展构建和发布包检查通过。新增回归覆盖旧 HTTP 地址、CDN 来源限制、题干及选项图片提取、题图材料保存与课程页面原图读取。

本版没有运行识别速度基准，也没有完成已安装 Edge 扩展或真实课程侧栏的现场验收。合成数据和自动化测试不代表平台已完成状态。
