# 0.5.9 升级说明

自动学习现在始终在前台运行，覆盖视频、音频、文档/PPT、图片阅读和章节题。默认全选五类任务；切换到其他标签页或窗口时，扩展会自动返回当前学习任务页，窗口最小化时会先恢复窗口。前台切换只改变标签页和窗口焦点，不刷新页面或重建播放器。

章节题及播放中弹出的题目通过同一前台控制器运行。答题队列带有所属学习队列标识，作答时由题目页持有前台，结束后交还学习流程。平台新建章节标签页会被当前学习接管；暂停、停止、队列结束、账号变化及平台拦截会释放前台控制。连续三次无法确认标签页和窗口已激活时，学习会暂停并记录 `foreground-unavailable`。

媒体中断继续使用平台最新状态及有界恢复；每次恢复前先激活并核对当前学习页。旧版 `foregroundFallback` 数据字段仍可读取，但不会改变前台行为。设置数据继续使用 schema 2；浏览器重启后的检查点仍按原流程暂停，继续时重新核对目录并使用前台流程。

本版调整了媒体加载和页面变化后的恢复行为。本地类型检查、回归测试和浏览器夹具只能说明各自覆盖的范围，不代表所有平台页面都已验收。可重复的本地检查见 [验收说明](acceptance.md)。

## 安装

使用 `chaoxing-task-assistant-0.5.9-edge.zip` 或 `dist/edge-unpacked`。替换原扩展目录，在 `edge://extensions` 重新加载，再刷新学习通页面。保持原安装身份以保留配置。

本版没有更改设置数据格式。旧队列中的 `foregroundFallback` 仅作为兼容数据读取，不再影响行为。
