# 0.6.0 升级说明

本版在题目详情中加入 LaTeX 公式渲染，支持 `\(...\)`、`\[...\]`、`$...$` 和 `$$...$$`。编辑及 TXT 导出继续保留原始公式文本。公式图片按文件实际内容识别，兼容平台错误或缺失的格式标记。

无法可靠转成文字的题目图片会作为原图材料保存在本机 IndexedDB，后续生成或重新生成参考答案时，扩展会将图片与对应题目和选项一起发送到已配置的视觉服务。题目详情支持预览和下载原图。材料按账号、任务、页面和图片绑定，最多占用 64 MiB、有效期 7 天；图片字节及资源地址不会写入准备元数据、日志或 TXT。材料缺失或过期时需要重新识别，不会只凭图片占位文字请求模型。

清晰的小型单字母或数字图形，在两次高置信度 OCR 结果一致且没有视觉识别冲突时会直接还原为行内公式，不会仅因为内容是单个字形而保留图片。无法可靠转录的其他图片内容仍以原图供视觉作答。

生成参考答案仍只生成候选，不会填写、保存或提交。是否需要人工检查取决于题型支持情况、文字及答案证据；音视频题、简答及附件等不支持题型仍需人工处理。题目页本身不会自动调用模型；发送图片时使用用户配置的视觉服务，服务方的数据处理政策适用。

本地类型检查、自动化测试及打包不代表真实课程页面验收，范围见 [验收说明](acceptance.md)。

## 安装

使用 `chaoxing-task-assistant-0.6.0-edge.zip` 或 `dist/edge-unpacked`。在 `edge://extensions` 替换原扩展目录并重新加载，再刷新学习通页面。保持原安装身份以保留本机设置和历史。

设置数据仍为 schema 2，本版不要求迁移。
