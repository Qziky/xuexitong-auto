# 0.6.2：失败识别结果与原图缓存失效修复

再次生成候选时，旧版本可能直接复用处于待检查状态的整份结果，导致图片读取失败或模型超时后无法正常重试。修改设置时，失败题目也可能被误列入可保留名单；原图被本机存储淘汰或到期后，会话结果则仍可能保留已失效的材料引用。

本版调整：

- 整份候选复用前检查题目文字、原图引用与答案是否完整，失败或缺失结果重新处理。
- 保留名单只接纳已确认的题目；重新识别时检查原图是否仍存在、是否到期，以及账号、任务、页面和图片归属是否一致。
- 失效题目从当前页面重新提取资源地址；其他已确认文字继续保留。完整但需人工核对的候选仍可正常复用。
- 继续保留 0.6.1 的课程页面图片读取修复。原图地址仅在提取与识别期间使用，不持久化到会话缓存。

更新时重新加载现有扩展，确认版本为 0.6.2，再点击“重新识别文字”或出错题目的“重新识别”。无需清除全部浏览器缓存或扩展设置。安装或打开页面不会自动调用模型或提交作业；识别与生成候选仍由用户显式触发。

发布产物同时提供 `.output/edge-mv3` 与 `dist/edge-unpacked` 两个加载目录，以各自 `manifest.json` 的版本为准。

验证覆盖图片失败后的重试、设置变化后的保留名单、模型超时后的重试，以及原图到期、容量淘汰、清除和归属不匹配。实际安装的 Edge 扩展与当前课程侧栏仍需更新后核验。
